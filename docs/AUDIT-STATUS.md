`data/scores/corpus_bias_coefficients.json` (+ `_fr`, `_de`) were generated by the **old, attenuating** estimator: every stored coefficient understates true bias by ~(k−1)/k for match groups of size k (a corpus compared only in 2-corpus groups carries half its true bias). The estimator is fixed; the JSONs are not regenerated.
